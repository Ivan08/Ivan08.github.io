# ivan08.github.io

Личная страница-портфолио Ивана Переломова. Статический сайт без сборки: HTML, CSS и JavaScript.

## Как править

Весь контент лежит в `assets/js/data.js`:

- `SENIOR` — уровень пунктирной линии на круге компетенций (0–100);
- `AXES` — оси круга, `level` у каждой — уровень (0–100), `stack` — теги;
- `TASKS` — решённые задачи: точки на круге (`axis`) и на ленте пути (`job`);
- `JOBS` — этапы ленты пути;
- `PROJECTS` — проекты и их скриншоты из `assets/img/projects/`.

Тексты первого экрана, блока «Что получит бизнес» и контакты — в `index.html`.

## Цветовая тема

Пять тем заданы переменными в начале `assets/css/style.css`: `blue`, `green`, `violet`, `mono`, `warm`.
Тема по умолчанию — атрибут `data-theme` у `<html>` в `index.html`. Посмотреть другую: `?theme=green` в адресе
или кружки в шапке (временный переключатель — блок `#themes` в `index.html` и раздел «выбор темы» в `assets/js/main.js`).

## Локальный просмотр

```
python3 -m http.server 8000
```

Затем открыть http://127.0.0.1:8000.
